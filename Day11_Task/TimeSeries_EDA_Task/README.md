# Time Series EDA Pipeline

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a PPG (Photoplethysmography) Time Series Dataset.

The pipeline automatically performs:

* Dataset Summary
* Missing Value Analysis
* Time Continuity Check
* Statistical Analysis
* Feature Engineering
* Trend Detection
* Seasonality Detection
* Outlier Detection
* Stationarity Testing
* ACF/PACF Analysis

## Dataset

Input file:

data/sakshi_ppg.csv

## Execution

Run:

python main.py

## Output

All generated reports and plots are stored inside the artifacts folder.
